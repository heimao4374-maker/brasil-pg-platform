# BrasilPG - 高级 SEO 内容架构方案

## 项目概述
**目标**：构建权威型 PG 平台，通过内容优化和结构设计实现高排名和快速收录

**核心策略**：
- 内容权威化：通过专业指南、评测、对比建立信任
- SEO 架构化：清晰的信息层级和关键词分配

## 三、内部链接策略

### 主要流向路径
```
首页 → 游戏分类 → 单游戏详情
首页 → 新手指南 → 具体指南
首页 → Blog → 文章详情
首页 → 排行榜 → 排行榜详情
```

### 链接密度和锚文本
- **自然锚文本**：「查看完整指南」、「了解更多」
- **关键词锚文本**：「Slots 最佳策略」、「Crash games 初学者指南」
- 每页**3-5个**内链
- 避免过度优化（不要超过5%关键词锚文本）

## 五、技术 SEO 要求

### 网站结构
```
brasilpg.com/
├── / (首页)
├── /jogos/
│   ├── slots/
│   ├── crash/
│   ├── roleta/
│   └── cartas/
├── /guia/
│   ├── seguranca/
│   ├── iniciantes/
│   ├── deposito-saque/
│   └── estrategia/
├── /blog/
├── /faq/
├── /ranking/
├── /suporte/
├── /sobre/
├── /termos/
└── /privacidade/
```

### robots.txt 配置
```
User-agent: Googlebot
Allow: /
Allow: /blog/
Disallow: /admin/
Disallow: /private/
Crawl-delay: 1
```

### sitemap.xml
- 包含所有页面
- 每天更新一次
- 优先级分配：首页 1.0，分类 0.8，文章 0.7

### Schema 标记
- Organization（公司信息）
- LocalBusiness（位置和联系）
- BreadcrumbList（导航面包屑）
- FAQPage（FAQ 页）
- Article（文章）
- Review（评论）
